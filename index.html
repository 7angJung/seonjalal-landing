개인화 선물 추천 서비스 · MVP 개발 중

선잘알

취향을 몰라도, 더 잘 맞는 선물을 고를 수 있도록

선잘알은 선물 수신자의 취향, 비선호 카테고리와 선물 수신 이력을 반영하여 선물 선택의 불확실성과 중복 가능성을 낮추는 개인화 추천 서비스입니다.

해결하려는 문제

기존의 인기 상품 중심 추천만으로는 수신자가 원하지 않는 카테고리나 이미 받은 상품을 피하기 어렵습니다. 선잘알은 수신자 중심의 정보를 추천 과정에 반영해 더 적합한 선택을 돕습니다.

핵심 기능

  • 수신자별 비선호 카테고리를 반영한 상품 추천
  • 받은 선물 이력 조회와 중복 가능성 완화
  • 관계·목적·예산을 활용한 상황 맞춤 추천 확장

개발 현황과 계획

  • 현재 핵심 기능과 사용자 흐름을 구현하는 MVP 개발 단계
  • 다음 단계 초기 사용자를 대상으로 기능과 추천 경험 검증
  • 확장 계획 선물 이력·후기·자연어 입력을 활용한 추천 고도화

AWS 활용 계획

MVP 운영을 위해 애플리케이션 실행 환경, 데이터베이스, 상품 이미지 저장소와 모니터링 환경을 AWS에 구성하고, 사용자 증가에 따라 확장 가능한 구조를 단계적으로 검증할 계획입니다.

팀 소개

선잘알은 카카오테크 부트캠프에서 시작된 팀 프로젝트입니다. 취향저격단은 MVP 출시와 초기 사용자 검증을 목표로 서비스를 개발하고 있습니다.
